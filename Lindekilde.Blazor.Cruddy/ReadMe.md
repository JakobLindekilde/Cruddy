# Cruddy

## About
A simple ASP.NET Blazor component that could do CRUD operations on any database table

## Key Features
- Cruddy requires a model class or record
- Uses DataAnnotations (if any) for validation when editing or creating
- Cruddy uses Dapper - not Entity Framework

## How to Use
See CruddyDemo project for examples of how to use the Cruddy component.

## Main Types
The main types provided by this library are:
- `Lindekilde.Blazor.Cruddy.Components`
- `Lindekilde.Blazor.Cruddy.Helpers`
- `Lindekilde.Blazor.Cruddy.Repositories`
